# Beautify

让 Obsidian 的文件列表像 Notion 一样工作。前身是 Branch & Order(合并 Branch Note 与 Explorer Order Editor),因功能早已超出"合并"而更名;数据自动升级迁移。

## 功能

**页面(v2.0.0 起为原生重写,行为对齐 Branch Note)**
- 目录即页面:点击文件夹打开同名首页笔记(`目录/目录.md`);无首页时显示"开始书写"引导页
- **双击展开/收起子项**(v2.6.0,默认开启,设置 → 交互):文件列表中**双击**仍有子文档的文档展开其子文档列表,再次双击收起;单击仅打开笔记,无子文档的不受影响,折叠箭头保持原生的展开/折叠切换
- 行内 hover **＋**:文件列表中鼠标移到任意文件夹/笔记名称右侧出现 + 号,点击即新建子文档(与右键"新建子笔记"完全一致,支持晋升与撤销)
- 右键:删除首页、设置图标、排序方式(手动/名称/最近修改/创建时间);行内 hover ＋ 新建子文档(新笔记默认排在最后)
- **空首页退格删除**(v2.8.0):首页正文完全为空时,编辑器里按退格/删除键即删除首页(进回收站、可撤销),等价于右键「删除首页」;非空内容不受影响
- 重命名目录自动同步首页名;外部重命名自动跟随;撤销上次页面操作;未保存草稿恢复

**排序(v2.0.0 起为原生重写,行为对齐 Explorer Order Editor)**
- 保存的手动顺序(拖拽换序、右键"设置排序"弹窗、上移/下移/置顶/置底命令)
- 排序数据存于 `Beautify.md` 配置笔记内(orderEditor 槽位的 index 字段);不生成任何单独的排序文件,旧版 `explorer-order.md` 与 v1.x 的 indexBackup 备份在启动时自动迁移
- 文件/目录的重命名与删除自动跟随已保存的排序;目录重命名同步排序键

**Notion 化增强(宿主层)**
- ` ```bn-children ` 子页面列表块:首页内自动渲染子页面(按保存顺序,支持排序模式),带"＋ 新建子页面"按钮,文件变化自动刷新
- 子笔记模板(`{{title}}`/`{{date}}`/`{{time}}` 占位符)
- 文件夹子项计数徽章
- 每文件夹排序模式(手动/名称/最近修改/创建时间)
- **设置界面完整跟随语言设置**——包括 Explorer Order 区域的中文翻译
- **图标**(简化版 Iconic):右键任意文件/文件夹 → 设置图标 → 弹出选择面板(彩色 emoji 表情约 500 个 + 线条图标约 360 个,支持中文关键词搜索、随机选择、移除);**新笔记默认自动随机分配一个彩色 emoji 图标**(设置中可关);已从 Iconic 迁移的 emoji 图标继续正常显示;图标同时显示在 bn-children 列表中
- **隐藏规则**(简化版 Hide Folders):设置中每行一条规则——不含 / 的按名称隐藏任意同名文件夹,含 / 的按路径隐藏该项及子内容;左上角眼睛按钮(或命令/设置开关)临时显示被隐藏文件;已从 Hide Folders 自动迁移规则
- **视图模式**(v2.7.0,参考 [obsidian-auto-view-mode](https://github.com/saltyfireball/obsidian-auto-view-mode) 重写;v2.9.0 起改由右上角切换直接设置,v2.10.0 移除右键菜单):笔记属性 `auto-view-mode`(可自定义)指定打开时的视图——`reading`/`preview` = 阅读视图、`edit`/`live` = 实时预览、`source` = 源码模式;点编辑器右上角切换(或 Ctrl+E)即切换并记忆该笔记,切回库默认视图自动清除记忆;每个标签页只应用一次,之后手动切换不被覆盖;无 layout-change 监听、无全库扫描,打开一篇笔记的常驻开销仅一次缓存查询 + 一次 WeakMap 读取
- **文档收藏**(v2.10.0 独立开关,设置 → 交互):右键文件/文件夹收藏,收藏区显示在文件列表顶部
- **最近打开**(v2.10.0 独立开关,设置 → 交互):最近打开的笔记显示在文件列表顶部(收藏过的不再重复显示)

**任务管理**(v2.1.0 按 [obsidian-tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) 模型重构,v2.2.0 视图重做)
- **一切元数据行内化**:任务就是普通 Markdown,元数据以表情字段写在行尾,随库同步、任何编辑器可见——`➕ 创建 ✅ 完成 ❌ 取消 🛫 开始 ⏳ 计划 📅 截止 🔺⏫🔼🔽⏬ 优先级`,字段顺序不限(解析从行尾循环剥离,兼容行中字段的容错回退)
- `[] + 空格` 快速建任务并即时盖 `➕ 今日` 戳;勾选自动盖/撤 `✅ 日期`(阅读视图的复选框也能直接勾选回写)
- **图标 = 描述行首的表情**:纯文本,实时/源码/阅读视图、其他设备全部可见;编辑弹窗、编辑器悬停条都能改
- **编辑弹窗**:描述、状态、图标、四个日期、优先级,保存只重写那一行;命令「编辑光标处任务」或悬停工具条进入
- 悬停任务行出现三键工具条:[设图标] [编辑] [转子页面];转子页面保留全部行内字段,`[[内链]]` 与 `[名称](路径.md)` 两种格式都识别
- **任务视图(v2.2.0,参考思源片趣多视图)**:不再是侧边栏,而是一份「任务视图」文档——命令「打开任务视图」首次自动创建(`任务视图.md`),内含一个代码块,渲染三个视图,**阅读与实时预览通用,任务变动自动刷新**:
  - **工作台**:统计卡片(待办/今日到期/已逾期/重要/今日完成/本周完成)、今日聚焦(逾期+今日到期)、优先级分布条形、最近完成
  - **看板**:待办/已完成/已取消三列,卡片可拖拽换列(自动盖 ✅/❌ 戳),点卡片打开编辑弹窗,复选框直接勾选
  - **四象限**:按"重要(⏫ 及以上)× 紧急(今明两天或逾期)"自动分象限;**卡片可拖拽换象限**——自动补齐/清空/推后对应字段(拖入重要=补 ⏫,拖入紧急=截止今天,拖出不紧急=到期推后一周),点卡片可精修

## 从 Branch & Order / 两个原插件升级

首次启用时自动迁移:
- 来自 **Branch & Order / Beautify 旧版**:整套设置原样导入(语言、排序设置、模板、排序模式等);v2.0.0 起排序数据统一为 `Beautify.md` 槽位里的 `index` 字段,旧格式(v1.x 的 indexBackup 备份文本、更早的 `explorer-order.md` 笔记文件)启动时自动转换,旧笔记移入回收站
- 来自 **Branch Note + Explorer Order Editor**(从未用过合并版时):分别导入各自 data.json 与排序笔记,无需任何操作

注意:命令前缀从 `branch-order:` 变为 `beautify:`,如绑定过快捷键需重新绑定。

## 技术说明

v2.0.0 起全部为可读的原生代码,不再内嵌任何压缩产物:排序核心(原型层补丁、拖拽换序、原生 HTML5 拖拽的设置弹窗、重命名/删除跟随)与页面核心(目录即页面、子笔记服务、串行队列与撤销)均为原生实现,行为对齐两个原插件;宿主层负责编排、存储(`Beautify.md` 分槽)、图标、隐藏规则、任务管理与统一设置页。实例层动态解析原型链,与补丁加载顺序无关;冷启动竞态与 Obsidian 1.14 点击分发变更均已处理。带加载自诊断通知。
